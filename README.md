# Domain-specific fine-tuning of Cellpose-SAM for neuronal somata

Code accompanying the article **"Automated Segmentation and Morphometric Assessment of Neuronal Somata in the Rat Trigeminal Ganglion Using a Fine-Tuned Cellpose-SAM Model"** (Zilli, dos Santos, Prado, Lopes, Chichorro).

The notebooks reproduce the full pipeline of the article: training-hyperparameter exploration, 5-fold cross-validation with and without data augmentation, inference-parameter calibration, morphometric comparison with the manual reference, and all figures.

## Quick start

1. Request the data and models (see above) and arrange them in the folder layout below.
2. Open a notebook in [Google Colab](https://colab.research.google.com/) (or Jupyter).
3. In the **Paths** cell, set `PROJECT_DIR` to the folder that contains `dataset/`, `models/` and `results/`. On Colab, mount Google Drive first:
   ```python
   from google.colab import drive
   drive.mount('/content/drive')
   PROJECT_DIR = Path("/content/drive/MyDrive/<your_folder>")
   ```
4. Run the notebook. Each notebook lists in its **Required files** table which file goes into each path variable.

**Reproducing the figures only (no GPU).** With the provided `results/` files:
- `Phase5_figures.ipynb` → *Run all* (Figures 2–7).
- `Phase4_morphology_measurements.ipynb` → run sections 1–4, skip sections 5–6 (segmentation of all folds and pre-trained baseline), then run sections 7–8 (Table 1 and Figure 8). Section 9 (Figure 9) runs one model on one image and is faster with a GPU.

**Reproducing the full pipeline.** Run the notebooks in order (Phase 1 → Phase 5) on a GPU runtime. Each notebook writes the inputs of the next one into `results/` and `models/`.

## Repository contents and correspondence with the article

| Notebook | Article | What it does | GPU |
|----------|---------|--------------|-----|
| `Phase1_training_hyperparameter_exploration.ipynb` | Methods 2.4.1 · Results 3.1 | Sequential search of epochs, learning rate and weight decay, then a learning rate × weight decay grid, on a fixed 21/5 hold-out split; selection by AP@50 with the one-standard-error rule | Yes |
| `Phase2_generalization_data_augmentation.ipynb` | Methods 2.4.2 · Results 3.2 | 5-fold cross-validation of the selected configuration (100 epochs, lr = 1e-5, wd = 0.1), without (A) and with (B) data augmentation — 10 models | Yes |
| `Phase3_inference_parameter_optimization.ipynb` | Methods 2.4.3 · Results 3.3 | `diameter` and `min_size` from the validation ground truth; `flow_threshold` × `cellprob_threshold` grid on the validation set; re-evaluation on each test fold | Yes |
| `Phase4_morphology_measurements.ipynb` | Methods 2.5 · Results 3.4 · **Table 1** · **Figures 8–9** | Segmentation of all test folds with the optimized models; morphometric descriptors (`regionprops`); neuron counting; pre-trained baseline | Partly |

## Folder layout

```
PROJECT_DIR/
├── dataset/
│   ├── train/        21 images <id>.tif + Cellpose annotations <id>_seg.npy
│   ├── test/          5 images (1, 7, 10, 15, 17) + <id>_seg.npy
│   └── validation/    5 images (3.2.2, Valid1–Valid4) + <id>_seg.npy
├── models/
│   ├── A_no_augmentation/     A_no_augmentation_fold_{1..5}_ep100_lr1e-05_wd0.1.pth
│   └── B_with_augmentation/   B_with_augmentation_fold_{1..5}_ep100_lr1e-05_wd0.1.pth
├── results/
│   ├── phase1/   phase1_all_results_consolidated.csv, <sub-phase>/results_final.json
│   ├── phase2/   phase2_all_results.csv, <condition>/results_final.json
│   ├── phase3/   phase3_test_evaluation.json, phase3_validation_gridsearch.json
│   └── phase4/   morphology_gt_allfolds.csv, morphology_pred_allfolds.csv, neuron_counts_allfolds.csv
└── figures/
```

The 26 cross-validation images are pooled in the order *sorted train names + sorted test names*; this order defines the folds (`KFold(n_splits=5, shuffle=True, random_state=42)`) and must be kept.
